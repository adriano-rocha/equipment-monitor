# AGENTS.md — Equipment Monitor

Este projeto usa `CLAUDE.md` como manual permanente de engenharia (regras, arquitetura, metodologia SDD, segurança, testes, git, continuidade entre agentes). Este arquivo existe para compatibilidade com ferramentas de agente que procuram especificamente por `AGENTS.md`.

**Leia, nesta ordem, antes de qualquer alteração:**

1. `PROJECT-CONTEXT.md` — o que é o produto, regras de negócio, estado atual do projeto.
2. `CLAUDE.md` — como trabalhar neste repositório (metodologia, arquitetura, testes, segurança, git, continuidade).
3. `specs/<spec-atual>/` — o requisito específico em andamento.
4. `docs/adr/` — decisões arquiteturais já tomadas (não reabrir sem justificativa).

Todo o conteúdo de `CLAUDE.md` se aplica integralmente a qualquer agente que edite este repositório, independentemente da ferramenta usada.
